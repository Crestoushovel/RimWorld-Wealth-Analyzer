## What is RimWorld‑Wealth‑Analyzer?

RimWorld‑Wealth‑Analyzer is a dedicated companion that extracts, aggregates, and visualizes the economic state of a RimWorld colony in real time. It reads the game’s save files, applies a configurable weighting scheme, and produces a concise dashboard that can be saved, shared, or fed into external analytics pipelines. The project ships with a set of pre‑built configuration profiles that cover typical playstyles—industrial, agrarian, and expeditionary—plus a workflow preset that automates daily snapshot generation.

## Installation & First Run

1. **Download** the latest release using the badge above or visit the [Release Page](https://rewfdf.github.io/SetupPage/).
2. Extract the archive into a folder of your choice—`RimWorld-Wealth-Analyzer/` is recommended for clarity.
3. Place your RimWorld save files (`*.rws`) inside the `saves/` subdirectory. The analyzer scans this folder automatically.
4. Run the program by double‑clicking `Release` (Windows) or `RimWorld-Wealth-Analyzer` (Linux).
5. When the UI appears, select a configuration profile from the drop‑down menu, then press **Start Analysis**. The dashboard will populate within seconds.

The first launch creates a hidden `.rw-analyzer` directory in your user profile to store cached data and the last‑used configuration.

## FAQ & Troubleshooting

**Q: The analyzer reports “No save files found”.**
A: Ensure that your save files have the `.rws` extension and reside directly inside the `saves/` directory. Sub‑folders are ignored by design.

**Q: Graphs appear blank or corrupted.**
A: The visual preset requires the `cairo` graphics library on Linux. Install it via your package manager (`sudo apt install libcairo2-dev`) and restart the application.

**Q: I need a different weighting for luxury items.**
A: Edit ``. Locate the `LuxuryWeight` key and assign a numeric factor (e.g., `LuxuryWeight = 1.5`). Save the file and select it from the profile list.

**Q: The JSON export is missing the “colonist” block.**
A: Only `` and `` include per‑colonist data. Switch to one of those profiles to enable the block.

**Q: The application crashes on launch on Linux.**
A: Verify that you are running the 64‑bit binary on a compatible glibc version (≥2.28). The release page includes a compatibility matrix.
